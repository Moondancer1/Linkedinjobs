# LinkedIn EU Jobs → Telegram

Бот ищет вакансии по Евросоюзу на публичных страницах LinkedIn (без входа в аккаунт), оставляет только те,
где в тексте есть email или телефон, и присылает карточки в Telegram. Запускается и останавливается командами в чате.
Работает на обычном компьютере, сервер не нужен.

## Запуск на любой машине

Нужен только **Python 3.10+** ([python.org](https://www.python.org/downloads/); на Windows поставьте галочку «Add python.exe to PATH»).

```bash
git clone <ваш-репозиторий> linkedin_jobs_bot
cd linkedin_jobs_bot
```

- **Windows:** двойной клик по `start_bot.bat`
- **macOS / Linux:** `bash start.sh`

На новой машине скрипт сам создаст окружение, поставит зависимости и браузер (несколько минут, один раз).
Потом бот спросит **токен** (из [@BotFather](https://t.me/BotFather)), попросит написать ему любое сообщение в Telegram
и сам определит ваш chat id. Всё, `.env` создан. В следующие разы бот стартует сразу.

Дальше управляйте из Telegram-чата с ботом.

## Команды

| Команда | Что делает |
|---|---|
| `/go` | начать поиск |
| `/stop` | остановить |
| `/keywords a, b, c` | ключевые слова (`/keywords all` — без фильтра, `/keywords` — показать) |
| `/mode remote\|hybrid\|both\|any` | формат работы: чистый ремот, гибрид, ремот или гибрид, любой |
| `/period 1h\|1d\|1w\|1m` | за какой период искать |
| `/maxcompany N` | не больше N вакансий одной компании за проход (0 = без лимита) |
| `/delay N` | пауза в секундах между карточками |
| `/status` | текущее состояние и настройки |

Настройки сохраняются в базе `seen_jobs.db` и переживают перезапуск.

## Поиск кандидатов

`/find` — бот по очереди спросит должность, страну, город, образование, опыт, навыки и сколько профилей прислать.
На необязательные вопросы есть кнопка «Пропустить». В конце покажет условия и запросы, поиск начнётся после «Искать».
`/cancel` прерывает вопросы, `/stop` останавливает поиск. При следующем `/find` можно нажать «Повторить прошлый поиск»:
придут следующие профили, без повторов.

- У LinkedIn нет открытого поиска людей, поэтому бот ищет через DuckDuckGo запросом
  `site:linkedin.com/in "должность" "город" ...` и присылает заголовок, сниппет и ссылку на профиль. Сами профили не открывает.
- Опыт — это слово в запросе (junior, senior, «5 years»), а не точный фильтр по годам: стаж в выдаче поисковика не виден.
- Чем больше условий, тем меньше результатов. Если пусто, уберите город, образование или навыки.
- Если поисковик показал капчу или ничего не нашёл и в `.env` есть `GEMINI_API_KEY`, бот повторит запрос через Gemini
  с поиском Google. В таких карточках описание пишет Gemini, сверяйте его с профилем.
- Вёрстку DuckDuckGo бот читает в `ddg_search()` и `parse_profiles()`: если она поменяется, править там.

## Как это устроено

- Ищет в `LOCATION` (по умолчанию European Union), открывает каждую вакансию и ищет email и телефон
  (в том числе номера без «+» после слов tel/phone/call: код страны берётся из локации вакансии).
- Фильтр формата (ремот/гибрид) работает по словам в тексте: бесплатный вход в LinkedIn не показывает значок типа работы.
- Не присылает дубли: по ID вакансии и по связке «компания + название + город» за 30 дней.
- Защита от блокировок: смена User-Agent, случайные паузы, повтор с ожиданием при ответах 429/999.
- Необязательно: в `.env` можно указать ключ Gemini или DeepSeek, тогда модель поищет контакты в тексте,
  когда обычный поиск ничего не нашёл. Принимается только то, что буквально есть в тексте вакансии.

## Что не попадает в git

`.gitignore` исключает `.env` (токен), `.venv/` и `seen_jobs.db`. Репозиторий лучше держать **приватным**.
Если токен всё же попал в историю git или в чат, отзовите его: @BotFather → `/mybots` → ваш бот → API Token → Revoke.

## Несколько машин

- Бот должен работать **только на одной машине одновременно**, иначе Telegram отдаёт команды одной копии, второй будут ошибки 409.
- История просмотренных вакансий и настройки лежат в `seen_jobs.db` на каждой машине отдельно. Чтобы они ездили с вами,
  положите базу в синхронизируемую папку (OneDrive, Dropbox) и укажите путь в `.env`: `DB_PATH=...`.
  Тогда новая машина не станет присылать старые вакансии заново.
- Компьютер не должен уходить в сон, пока бот работает.

## Проверка

```bash
.venv/Scripts/python test_contacts.py      # Windows
.venv/bin/python test_contacts.py          # macOS / Linux
```

Должно закончиться строкой `env setup ok`. Поиск кандидатов проверяется так же: `test_candidates.py`, в конце `candidates ok`.

## Ограничения

- LinkedIn отдаёт около 1000 результатов на один поисковый запрос: чтобы охватить больше, задайте несколько ключевых слов.
- Автоматический сбор данных может нарушать пользовательское соглашение LinkedIn. Держите паузы умеренными.
- Если LinkedIn поменяет вёрстку, поправьте CSS-селекторы в `search()` и `enrich()`.
